## Age Checker GUI (Tkinter)

A simple Python GUI application I built with Tkinter that checks a user’s age and displays a message based on voting eligibility and senior status.

### What it does

* Accepts age input from the user
* Uses a button click to trigger logic
* Displays results directly in the GUI window:

  * Under 18 → not eligible to vote
  * 18–65 → old enough to vote
  * Over 65 → senior citizen

### Concepts demonstrated

* Tkinter GUI setup
* Labels, Entry widgets, and Buttons
* Event-driven programming
* Conditional logic (`if / elif / else`)

### How to run

```bash
python lab6.py
```
