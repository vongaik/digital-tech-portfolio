# Password Validation Program (Python)

This project is a Python program I developed for a lab assignment focused on string manipulation and input validation. The program verifies whether a user-entered password meets a defined set of security requirements.

## Project Purpose

The goal of this program is to validate a password based on common security rules using Python string methods and conditional logic. The program prompts the user for input and reports whether the password is valid or invalid.

## Password Requirements

A valid password must meet **all** of the following conditions:

- Be at least **9 characters long**
- Contain **at least one uppercase letter**
- Contain **at least one lowercase letter**
- Contain **at least one numeric digit**
- Contain **at least one special character** from the following list:
  - `#`, `!`, `$`, `_`

If any requirement is not met, the password gets rejected.
