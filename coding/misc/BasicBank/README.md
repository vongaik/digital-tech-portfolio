# Basic Bank Account Simulator (Java)

A simple Java program I made that demonstrates the use of **do-while loops** and **sentinel-controlled loops** to simulate a basic bank account system.

## Features

- Start with a default balance of $1000.  
- Make deposits and withdrawals.  
- Display current account balance.  
- Menu repeats until the user chooses to exit.  
- Handles invalid menu selections gracefully.  


## Tech Stack

- Java  
- Standard Input via `Scanner`  
- Control flow: `do-while` loop, `if-else` statements
