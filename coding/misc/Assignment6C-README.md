# Overloaded Sort – Java (Assignment 6C)

A console program I made demonstrating **method overloading** and sorting for multiple data types (int, char, float) in Java. Users enter 8 values of their chosen type, and the program sorts them using type-specific `sortArray()` methods.  

## Purpose & Skills
- Demonstrates **method overloading** for different primitive types.  
- Uses **1D arrays**, **Scanner input**, and **Java Arrays.sort()**.  
- Shows clean, reusable code and understanding of Java fundamentals.
