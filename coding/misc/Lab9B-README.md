# Binary Bubbles (Java)

A simple Java program I did that demonstrates **sorting and searching**. User enter 11 integers, the program sorts them using **BubbleSort**, then searches for a target value using **Binary Search** while displaying key indices (`low`, `mid`, `high`) during the search.

## Skills Demonstrated
- Loops (`for`, `while`)
- Arrays
- Bubble Sort algorithm
- Binary Search algorithm
- User input handling with `Scanner`

Both sorting (Bubble Sort) and searching (Binary Search) are core fundamentals of DSA.
