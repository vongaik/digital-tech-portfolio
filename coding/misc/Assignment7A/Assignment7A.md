# Rare CD Collection Manager (Java)

A simple Java program demonstrating **Object-Oriented Programming (OOP)** concepts using classes, attributes, constructors, and methods. Users can create and manage a collection of Audio CDs, search by CD or artist, and display CD information.

## Key Features

- Uses `AudioCD` class with private attributes: title, artists, release year, genre, condition.
- Includes default and overloaded constructors.
- Getter and setter methods enforce valid attribute values.
- Interactive main menu for viewing CD info, searching by CD, or searching by artist.
- Demonstrates arrays of objects and basic OOP design principles.
